# International University Profile Library

本文件为非中国院校静态资源库占位索引。首版不预置具体院校事实；新增韩国、日本、英国、美国、加拿大、澳大利亚院校时，使用 `university-profile-library.md` 中的单校模板，并补齐 `核验来源`、`profile_source_status`、`适用范围` 和 `最后人工核验日期`。

条目仅用于非时效性背景；招生、专业、费用、截止日期、奖学金、签证、住宿、就业、认证和职业资格必须另查目标入学季和当前官方来源。
