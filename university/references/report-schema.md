## 轻量问答模式

Use this mode for narrow questions such as “介绍一下某校”, “这个专业能不能报”, “先帮我判断一下”, or other quick checks where a full report would be too heavy.

Default structure:

1. `简要结论`: 1-2 sentences or 2-3 bullets.
2. `依据与来源`: official source links, profile-library `profile_source_status`, and retrieval date when relevant.
3. `关键风险`: only risks that materially affect the user's decision.
4. `待核验项`: missing, current-year, login-only, conflicting, or time-sensitive items.

Keep the answer to 5-8 high-signal bullets unless the user requests a full report or the task involves high-stakes admissions, gaokao volunteer strategy, visa, credential recognition, fees, or multiple schools.

Examples:

单校介绍：

- `简要结论`：用资源库背景给出学校定位、城市和稳定特色；不加入招生、费用或截止日期。
- `依据与来源`：标注资源库 `profile_source_status`、官方主页、精确简介/概况页或 `待补充`、最后人工核验日期。
- `关键风险`：若 `profile_source_status` 为 `C`，提示“来源需复核”；若用户继续问招生信息，说明需查当年官方招生来源。
- `待核验项`：校区变化、办学性质、更名合并、院系调整等稳定背景疑点。

高考志愿初步判断：

- `简要结论`：先说明不能用分数直接判断能否录取，只能基于省份、年份、位次、批次和志愿模式做风险分层。
- `依据与来源`：省级教育考试院当年政策、招生计划、志愿系统、投档规则；阳光高考和高校招生章程用于辅助核验。
- `关键风险`：选科/科类不匹配、代码误填、组内调剂、体检/单科/外语限制、退档、征集志愿不确定。
- `待核验项`：省份、位次、一分一段表、批次线、目标专业组、是否服从调剂、不能接受清单。

海外本科申请：

- `简要结论`：把录取、签证、入境、学历认证、住宿和职业资格分开判断；不把 offer 当成其他结果的保证。
- `依据与来源`：学校项目页、所在国资质系统、学生签证官网、中国留服中心和领事安全渠道。
- `关键风险`：conditional offer 条件、押金退款、资金证明、签证前置文件、项目资质、认证和职业资格。
- `待核验项`：目标国家/入学季、申请路径、高考和高中成绩、语言成绩、预算、国内备选、住宿和签证节点。

## Single University Report

### 1. 基本信息

| 字段 | 内容 |
| --- | --- |
| 学校名称 | 中文名 / 英文名 / 当地语言名 |
| 国家/地区 | 国家、州/省/都道府县/城市 |
| 学校性质 | 公立、私立、国立、研究型、综合型等 |
| 官方网站 | 官方主页链接 |
| 资源库背景摘要 | 仅使用非时效性简介；招生、项目、费用、截止日期和政策不得写入此字段 |
| profile_source_status | `A` / `B` / `C`，来自资源库；未收录则写未收录 |
| 核验来源 | 资源库条目的官网、简介/概况页、信息公开页或教育主管页面 |
| 学校简介 | 办学历史、定位、规模、特色 |
| 优势学科 | 需注明来源或标记待核验 |
| 主要校区 | 如适用 |

### 2. 本科招生信息

| 字段 | 内容 |
| --- | --- |
| 招生对象 | 国际学生、本国学生、转学生等 |
| 申请入口 | 官方申请系统或招生页面 |
| 申请条件 | 学历、课程背景、成绩要求 |
| 语言要求 | IELTS、TOEFL、JLPT、TOPIK、英语授课项目要求等 |
| 标化考试 | SAT、ACT、EJU、A-Level、IB、高考、其他 |
| 申请材料 | 成绩单、推荐信、文书、作品集、护照等 |
| 时间线 | 开放时间、截止日期、录取通知时间 |
| 学费与费用 | 学费、申请费、其他必需费用 |
| 奖学金 | 奖学金名称、资格、申请方式 |
| 官方来源 | 链接和来源类型 |

### 3. 研究生招生信息

| 字段 | 内容 |
| --- | --- |
| 学位层次 | 硕士、博士、研究型、授课型、专业学位 |
| 招生单位 | 研究生院、学院、系、项目 |
| 申请入口 | 官方申请系统或项目页面 |
| 学术要求 | 学位、专业背景、GPA、先修课程 |
| 语言/标化 | IELTS、TOEFL、GRE、GMAT、JLPT、TOPIK等 |
| 导师/研究计划 | 是否需提前联系导师、研究计划要求 |
| 申请材料 | 成绩单、CV、PS、推荐信、研究计划、作品集等 |
| 截止日期 | 按项目、学院、轮次或入学季列出 |
| 学费与资助 | 学费、奖学金、助研/助教、减免 |
| 官方来源 | 链接和来源类型 |

### 4. 专业类目

| 学院/学部 | 专业/项目 | 学位层次 | 授课语言 | 学制 | 官方链接 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |

### 5. 信息质量

| 字段 | 内容 |
| --- | --- |
| 官方来源数量 | 数量和来源类型 |
| 非官方来源 | 是否使用，使用目的 |
| 检索日期 | YYYY-MM-DD |
| 时效口径 | 时效字段默认采用目标年份、目标入学季或当前官方来源；2026 高考最终填报结论必须使用 2026 官方来源，历史数据只能用于比较 |
| 证据台账 | 高影响或时效字段按 `source-evidence-ledger.md` 记录字段级证据 |
| 待核验项 | 缺失、冲突、过期、需登录的信息 |
| 重要提醒 | 政策变动、项目差异、年份限制 |

## 中国高考志愿填报分析

Use this schema when the user asks about China mainland gaokao volunteer filling for mainland universities.

### 0. 用户画像摘要

| 字段 | 内容 |
| --- | --- |
| 已知信息 | 省份、年份、科类/选科、分数、位次、批次、目标方向等 |
| 缺失关键信息 | 会影响可报范围、投档、调剂、退档或风险判断的信息 |
| 核心取舍 | 学校/专业/城市/公办/费用/距离/升学就业等优先级 |
| 风险偏好 | 进攻、均衡、保守；冲稳保和调剂接受度 |
| 不能接受清单 | 民办、专科、高收费、外省、冷门专业、调剂、特殊义务等 |
| 待补充材料 | 一分一段表、招生计划、招生章程、体检、专项资格、近年同口径录取数据 |

先说明画像完整度，再给核验路径和分析结论；信息不足时标记 `待补充`。

### 1. 考生与场景

| 字段 | 内容 |
| --- | --- |
| 省份 | 考生所在省级教育考试院口径 |
| 年份 | 优先当年文件，如 2026；未发布则标记待核验 |
| 科类/选科 | 物理类、历史类、文史、理工、艺术体育类别、选考科目等 |
| 分数与位次 | 高考分数、省内位次、一分一段表来源 |
| 目标批次 | 提前批、本科批、专科批、专项计划等 |
| 志愿模式 | 院校专业组、专业（类）+院校、传统院校志愿等 |
| 特殊资格 | 专项、军警、公费师范、优师、定向医学生、艺术体育等 |

### 2. 志愿规则

| 字段 | 内容 |
| --- | --- |
| 志愿单位 | 院校、院校专业组、专业（类）+院校等 |
| 投档模式 | 平行志愿、顺序志愿、一轮投档、综合分投档等 |
| 调剂机制 | 是否存在专业组内调剂、是否无传统调剂、调剂范围 |
| 批次影响 | 提前批或特殊项目录取后是否影响后续批次 |
| 官方依据 | 省级教育考试院当年文件链接 |

### 3. 院校/专业核验表

| 志愿序号 | 院校 | 院校代码 | 专业组代码 | 专业/类 | 专业代码 | 计划人数 | 选科/科类 | 近年同口径位次 | 学费 | 校区 | 调剂 | 限制条件 | 官方省招来源 | 待核验 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

限制条件包括体检、单科成绩、外语语种、口试、性别、专项资格、高收费项目、培养地点、转专业限制等。

### 4. 风险标记

| 风险类型 | 风险说明 | 官方核验材料 | 处理建议 |
| --- | --- | --- | --- |
| 退档风险 | 专业分不足、不服从调剂、身体/外语/单科/选科不符等 | 招生章程、省级投档规则 | 标记低/中/高风险，不给保证性结论 |
| 误填风险 | 代码、批次、科类、专业组、校区、项目类型混淆 | 当年省招计划、志愿系统 | 逐项核对代码和备注 |
| 高收费风险 | 中外合作、软件类、国际项目、民办或独立学院转设 | 省招计划、招生章程、收费公示 | 明确费用和家庭承受度 |
| 特殊项目义务 | 军警、公费师范、优师、医学定向、专项计划等 | 省级文件、学校简章 | 核验资格、服务期、违约责任 |
| 征集志愿不确定性 | 余缺计划有限、窗口短、条件限制多 | 省级征集公告 | 不作为主要兜底方案 |

### 5. 来源证据台账

高考志愿任务涉及当年政策、招生计划、代码、投档规则、调剂、征集志愿、章程限制或费用时，按 `source-evidence-ledger.md` 记录字段级证据。

| 信息字段 | 结论摘要 | 来源类型 | 来源标题 | URL | 发布/更新日期 | 适用年份 | 适用人群 | 检索日期 | 证据等级 | 使用结论 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

## 中国高考生海外本科申请核验

Use this schema when a China gaokao candidate asks about applying to overseas undergraduate programs.

### 0. 用户画像摘要

| 字段 | 内容 |
| --- | --- |
| 已知信息 | 目标国家/地区、入学季、申请路径、成绩、语言、预算、专业方向等 |
| 缺失关键信息 | 会影响录取、签证、资金、认证、住宿或备选方案的信息 |
| 核心取舍 | 学校层次、国家/城市、专业、预算、是否保留国内志愿、毕业后路径 |
| 风险偏好 | 是否接受预科/桥梁/延期、押金风险、签证风险、认证不确定性 |
| 不能接受清单 | 高预算、非正规项目、认证不确定、远程课程、治安风险、无国内备选等 |
| 待补充材料 | 高考/高中成绩、语言成绩、毕业证明、护照、资金证明、offer 条件、住宿和签证节点 |

先说明画像完整度，再给官方核验路径和分析结论；信息不足时标记 `待补充`。

### 1. 申请路径

| 字段 | 内容 |
| --- | --- |
| 目标国家/地区 | 美国、英国、加拿大、澳大利亚等 |
| 入学季 | 年份、秋季/春季/其他 intake |
| 申请路径 | 高考直申、高中成绩、预科、国际大一、语言桥梁、社区学院/学院转学、中外合作衔接 |
| 学术材料 | 高考成绩、高中成绩、会考/学考、毕业证、成绩单翻译 |
| 语言要求 | IELTS、TOEFL、PTE、Duolingo、学校内测、语言班 |
| 关键截止日期 | 申请、语言、押金、住宿、签证、注册 |

### 2. 项目与资质核验

| 学校 | 项目 | 学位授予方 | 是否接受高考 | 官方录取页 | 官方资质系统 | 项目风险 | 待核验 |
| --- | --- | --- | --- | --- | --- | --- | --- |

官方资质系统可包括 DAPIP、recognised bodies / OfS、CRICOS、DLI、所在国教育主管或质量保障机构、中国留服中心认证院校查询和加强认证审查公告。

### 3. Offer、签证与资金

| 字段 | 内容 |
| --- | --- |
| Offer 类型 | conditional、unconditional、pathway、语言班、package 等 |
| 条件清单 | 成绩、语言、毕业证明、押金、CAS/CoE/I-20/LOA 等 |
| 签证路径 | 学生签证类型、前置文件、资金、体检、面签/生物识别、PAL/TAL/CAQ 等 |
| 资金估算 | 学费、住宿、生活费、保险、交通、签证、机票、续签、汇率和涨价 |
| 打工限制 | 官方学生签证工作规则，不作为主要学费来源 |
| 退款与延期 | 押金、学费、住宿、签证拒签、语言未达标、延期入学 |

### 4. 认证、职业和安全风险

| 风险类型 | 核验问题 | 官方来源 | 处理建议 |
| --- | --- | --- | --- |
| 学历认证 | 学习方式、证书真实性、颁证院校、项目是否被加强审查 | 留服中心、中国留学网 | 标记低/中/高风险 |
| 职业资格 | 医学、法律、护理、教师、工程等是否需执照 | 目标国/中国职业监管机构 | 不把学位等同于执业资格 |
| 入境合规 | 签证、CAS/CoE/I-20/LOA、材料真实性、线上足迹等 | 签证官网/使领馆 | 单独核验，不用 offer 替代 |
| 住宿安全 | 房源、房东、中介、押金、合同、退租 | 使领馆/学校住房服务 | 使用正规渠道并保留证据 |
| 双轨冲突 | 国内志愿、国外押金、签证、住宿、入学日期 | 省招办/学校/签证官网 | 制定退出和备选方案 |

### 5. 来源证据台账

海外本科申请涉及录取条件、offer、押金、签证、资金、CRICOS/DLI/SEVP/IEQAS 等资质、学历认证、职业资格或住宿安全时，按 `source-evidence-ledger.md` 记录字段级证据。

## Source Evidence Ledger

Use `source-evidence-ledger.md` for field-level source records. Light answers can use the compressed evidence table; full verification reports should include the full evidence ledger when the user asks for source checking, comparison, strategy, gaokao volunteer filling, overseas application, visa, credential recognition, fees, or deadlines.
