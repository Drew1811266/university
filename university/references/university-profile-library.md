# University Profile Library

用于存放相对稳定、非时效性的大学院校背景信息。该资源库只作为学校简介和院校概览的背景起点，不作为招生、申请、费用、截止日期、奖学金、语言要求、录取政策或项目开设情况的依据。

## 使用范围

可存放：

- 学校名称、所在国家/地区、城市和官网主页
- 学校类型与整体定位
- 历史与办学概况
- 相对稳定的优势领域或特色学科
- 主要校区或地理位置概况
- 官方核验来源、`profile_source_status` 和最后人工核验日期

不要存放：

- 招生要求、申请要求、录取政策、专业是否招生、招生人数
- 截止日期、学费、奖学金、语言要求、标化要求、申请材料
- 签证、住宿、就业、认证、职业资格等会随年份或政策变化的信息
- 未经官方来源核验的排名、声誉描述、宣传口号或第三方评价

## 资源库加载规则

先读 `references/university-profile-search-index.md`，定位目标学校是否收录及所在 50 校分段文件；再读本文件确认字段规则、`profile_source_status` 和维护限制；最后只打开目标学校所在分段文件。不要默认加载全部院校资源库。用户询问未收录院校时，说明资源库未收录，并回到学校官网核验。

索引字段使用：

- `资源库序号` 用于定位资源库顺序，不等同于精确排名结论。
- `检索关键词` 用于匹配中文名、英文名、别名、旧名或去括号写法。
- `精确来源状态` 决定输出语气：已记录可简洁引用；待补充只能作背景线索；需复核必须提示回官网确认。
- `使用提示` 优先于模型自行判断，尤其是 `B` 和 `C` 级条目。

## profile_source_status

- `A`：官网简介/概况页直接核验，且 URL 明确。
- `B`：官方入口或公开资料可辅助整理，但精确简介页待补充。
- `C`：官网入口可达但简介页不稳定，需回官网/信息公开栏目复核。

维护门槛：

- 新增院校默认最低为 `B` 级；没有官方主页的条目不得入库。
- 有精确学校简介、学校概况、信息公开或教育主管页面 URL 的条目标为 `A`。
- 官网入口可达但简介页不稳定、栏目迁移频繁或字段级来源不清的条目标为 `C`。
- `C` 级条目用于背景摘要时，必须提示“来源需复核”，并建议回官网简介、信息公开或学校概况栏目确认。
- 已找到精确简介页的学校，应把 `核验来源` 写成“官方主页 + 精确简介/概况页”，并将 `profile_source_status` 提升为 `A`。

输出强度：

- `A`：可写“学校官网简介/概况显示……”，但仍只限非时效性背景。
- `B`：写“资源库据官方入口和公开资料整理，精确简介页待补充”，避免使用“确认”“显示”“已核验”等强断言。
- `C`：写“资源库有背景线索，但来源需复核”，并建议回官网或信息公开栏目核验。

## 单校基础简介模板

| 字段 | 内容 |
| --- | --- |
| 学校名称 | 中文名 / 英文名 / 当地语言名 |
| 国家/地区与城市 | 国家、州/省/都道府县/城市 |
| 学校类型与定位 | 公立/私立/国立；综合型/研究型/专业型等 |
| 历史与办学概况 | 建校背景、办学传统、规模或定位的非时效性概述 |
| 优势领域或特色学科 | 相对稳定的学科强项；避免写即时排名 |
| 主要校区或地点 | 主校区、城市分布或地理特点 |
| 官方主页 | 学校官方主页 URL |
| 核验来源 | 官方主页、学校简介/概况页、信息公开页或教育主管页面 URL；没有精确页面时写 `待补充` |
| profile_source_status | `A` / `B` / `C`，按上方等级填写；这是整条资料状态，不是字段证据等级 |
| history_evidence | 历史字段的来源 URL、证据状态和核验日期；缺失写 `待补充` |
| campus_evidence | 校区字段的来源 URL、证据状态和核验日期；缺失写 `待补充` |
| institution_type_evidence | 办学性质和定位字段的来源 URL、证据状态和核验日期；缺失写 `待补充` |
| strengths_evidence | 优势领域或特色学科字段的来源 URL、证据状态和核验日期；缺失写 `待补充` |
| source_url | 本条目主要官方来源 URL；入口级来源必须说明 `入口级` |
| 适用范围 | 非时效性背景；不用于招生、费用、截止日期或政策判断。 |
| 非时效性核验提醒 | 名称、校区、合并、更名、办学性质等需要核验的稳定背景事项 |
| 最后人工核验日期 | YYYY-MM-DD；未知则写 `待补充` |

## 填写规则

- 优先使用学校官网、官方历史页面、官方简介页面、政府或教育主管机构页面。
- 用简短转述，不复制长段官方文案。
- 对无法确认或来源不足的信息写 `待补充`，不要猜测补全。
- 若学校发生更名、合并、独立学院转设、校区调整或办学性质变化，在核验提醒中标记。
- 资源库条目只可用于背景摘要；任何招生、专业是否在某省招生、费用、代码、计划人数、录取风险、调剂风险和退档风险都必须回到当年官方来源核验。
- 软科 2026 只保留为入库覆盖范围说明，不得出现在高考候选池、排序或风险判断中。

## A 级优先复核清单

滚动维护时优先把以下条目复核到 `A` 级：

- 软科 2026 第 1-100 名院校。
- 最近三轮用户查询过的院校。
- 发生更名、转设、合并、校区迁移、办学性质变化或官网栏目迁移的院校。
- `C` 级且用户实际查询过的院校。

可选运行 `scripts/profile_maintenance_queue.py` 输出 B/C、精确来源待补充和稳定背景字段可能变化的维护队列。该队列只决定资料库维护优先级，不参与高考候选池生成或风险排序。
