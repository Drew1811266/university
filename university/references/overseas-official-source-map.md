# Overseas Official Source Map

用于中国高考生海外本科申请和普通海外院校申请核验。该地图只提供官方入口类型和起始链接；具体学校、项目、offer、签证、资金、住宿、学历认证、职业资格和入境要求必须分别打开当年官方页面核验。

核心规则：offer 不等于签证，不等于能入境，不等于回国一定能认证，不等于住宿或职业资格有保障。

## 通用核验顺序

1. 目标大学官网和具体项目页：录取要求、是否接受高考成绩、语言要求、材料、截止日期、offer 条件、押金、退款、住宿和学费。
2. 所在国官方教育或质量保障系统：学校和项目是否被认可，是否允许国际学生持学生签证就读。
3. 所在国官方签证系统：学生签证类型、前置文件、资金、英语或语言、体检、生物识别、面签、工作限制和续签。
4. 中国教育部留学服务中心或中国留学网：学历学位认证、认证院校查询、加强认证审查公告和安全提醒。
5. 中国驻外使领馆、外交部领事保护和学校住宿服务：行前安全、诈骗、租房、紧急联系和保险。

## 国家任务核验路径

这些路径只用于组织核验步骤，不写成政策结论。每一步都要打开目标学校、目标项目和当年官方页面确认。

| 国家/地区 | 任务核验路径 |
| --- | --- |
| 美国 | 目标大学国际本科录取页 → DAPIP/SEVP School Search 核验学校 → offer 后确认 I-20 → SEVIS 与 I-901 费用 → F-1 或 M-1 签证页面 → 学校资金、住宿、保险和工作许可页面 → 留服中心与领事安全核验 |
| 英国 | UCAS 或学校 course page → 核验 degree-awarding body/recognised body 和 sponsor → conditional/unconditional offer 条件 → CAS → GOV.UK Student visa、资金与 IHS → 学校住宿和退款规则 → 留服中心与领事安全核验 |
| 加拿大 | 学校 international admissions → DLI list 核验学校 → offer/LOA → PAL/TAL；魁北克另查 CAQ → IRCC study permit、资金和工作限制 → 住宿和保险 → 留服中心与领事安全核验 |
| 澳大利亚 | 学校 course page → CRICOS 核验机构和课程 → offer 条件 → CoE → Genuine Student、subclass 500、OSHC、资金和工作时长 → 学校住宿与退款 → 留服中心与领事安全核验 |
| 日本 | 目标大学学部/入试页面 → Study in Japan/JASSO/EJU/JLPT 路径核验 → 入学许可或合格通知 → 在留资格认定证明书路径 → 日本驻外使领馆签证 → 住宿、保险和资格外活动 → 留服中心与领事安全核验 |
| 韩国 | Study in Korea 与目标大学国际招生页 → IEQAS 或教育主管入口核验 → 标准入学许可 → D-2 或 D-4 签证路径 → TOPIK/语言、资金、住宿和兼职限制 → 留服中心与领事安全核验 |

## 输出要求

- 每个结论都要标明来自大学官网、资质系统、签证官网、留服中心或使领馆渠道；无法核验时写 `待核验`。
- 不说 `保证录取`、`保证签证`、`保证认证`、`低分保名校`、`一定能入境`。
- 中介、排名、论坛、案例库和中文广告页只作线索，必须回到官方来源复核。
